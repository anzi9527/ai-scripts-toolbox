## 🚀 快速开始

```bash
# 克隆仓库
git clone https://github.com/anzi9527/ai-scripts-toolbox.git
cd ai-scripts-toolbox

# 按需运行（每个脚本都有 --help）
python zhihu_hot.py --help
python content_checker check 文章.md
```

> 全部纯 Python 标准库为主，不装框架不配环境，Windows/Mac/Linux 都能跑。
